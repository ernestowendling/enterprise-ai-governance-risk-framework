# Generative AI Standard

Generative AI requires controls for grounding, hallucination, harmful content, prompt injection, confidential-data leakage, intellectual property, provider change and user reliance. Product Owners define permitted users, data, tasks and prohibited uses. Outputs affecting customers, rights, obligations or material decisions receive competent human review.

Solutions use least-privilege access, approved models, prompt and output filtering, grounding where feasible, user disclosure, logging, red-team tests and incident response. External providers may not train on institutional data without explicit approval. Model/version changes are assessed before adoption. Evidence includes use-case evaluation, guardrail tests, red-team results, monitoring and user training. Review cycle: at least annual.
