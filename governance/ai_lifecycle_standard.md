# AI Lifecycle Standard

## Controlled lifecycle
`IDEA → INTAKE → CLASSIFIED → ASSESSMENT → VALIDATION → APPROVAL → DEVELOPMENT → PRE-PRODUCTION → PRODUCTION → MONITORING → REVALIDATION → RETIRED`

Suspension is available from any active stage. Stage entry requires recorded evidence and an accountable approver. Classification precedes detailed assessment; required validation and human-oversight controls precede approval; approval, release controls and an approved monitoring plan precede production. A failed gate records a finding and returns the use to the accountable owner. Retirement revokes access, archives evidence, disposes data in accordance with retention rules and updates the inventory. AI Governance owns the standard; Business and Technical Owners own execution. Review cycle: annual.
